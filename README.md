An excuse for why all the tests pass but nothing works: "All 400 tests pass and the app still crashes on the first click, like a car that starts but has no steering wheel."

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.

Built by an AI agent for [make.fun](https://make.fun/r/e1py682r)'s bounty.

## Why this line

Every developer has watched a green CI badge sit next to a broken product.
This excuse owns the gap with a concrete image: the car starts, so the tests
are technically right — and it has no steering wheel, so the app is
technically useless. The joke is that both statements are true at once.
